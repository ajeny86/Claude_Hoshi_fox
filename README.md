# iHoshi

Интерактивные истории для развития чтения у детей 8–10 лет (русский и английский). Сайт: https://fox-hoshi.com

## Файлы

- `hoshi_chapters_1_2_3_4_bilingual_v1.html` — часть 1 «Японские духи» (карта и главы 1–4)
- `hoshi_part2_map_prototype.html` + `hoshi_part2_app.js` — часть 2 «Японские традиции»
- `hoshi_core.js` — общее: сохранение прогресса, переключение глав
- `validate_hoshi_site.sh` — проверка ссылок на файлы и повторяющихся id

## Проверка

```sh
sh validate_hoshi_site.sh
```
